## 왜 이 검정인가

강제매도량의 대용치로 $|dOI|$(5분 OI 순변화)를 써 왔다. 그런데 그것은

$$|dOI| = \text{격리청산} + \text{교차청산} + \text{자발적종료} - \text{신규진입}$$

네 성분의 순합이라 회귀변수 측정오차가 계수를 0 쪽으로 감쇠시킨다.
Bybit `allLiquidation` 은 **전건 피드**라 강제분만 직접 측정한다
(Binance `forceOrder` 는 심볼당 초당 1건 스로틀 — 실측: 전 종목 90초 구독에 0건).

## 1. $\gamma$ 교차검증 — **성공**

호가 밴드에 $\mathrm{Cum}(u) = B u^\kappa$ 를 적합하고 $\gamma = 1/\kappa$ 를 얻는다.

| 방법 | $\gamma$ | 데이터 |
|---|---|---|
| **수익 회귀** | **0.875 ± 0.078** | 21종 639이벤트, 3.5년 (`VD_FINDINGS.md`) |
| **오더북 모양** | **0.861** | 27클러스터, 40시간 라이브 호가 |

$\kappa$ 중앙 **1.161** [p25 1.052, p75 1.356], 프로파일 적합 $R^2$ 중앙 **0.9897**,
사용 밴드수 중앙 6.

**데이터도 방법도 완전히 다른데 0.875 vs 0.861 이다.**
$\Rightarrow$ **구조식의 함수 형태는 검증됐다.**

심볼별 $\kappa$ 중앙: SOL 1.104 / XRP 1.106 / BTC 1.130 / ETH 1.350 / ADA 1.407 / DOGE 1.414.
알트일수록 호가가 볼록하다. 단 대부분 $n < 5$ 라 개별 값은 신뢰하지 말 것.

## 2. 청산은 호가를 먹지 못한다

$$V / D(\text{도달 최심}) : \text{중앙 } \mathbf{0.0065},\quad p90 = 0.035,\quad \max = 0.076$$

도달 최심 $u$ 중앙 2.00%, 그 깊이 중앙 **\$44.8M**. 청산 클러스터는 \$100K~\$2.26M.
가장 큰 건(BTC \$2.26M)도 2% 이내 호가의 **7.6%** 다.

이전 독립 측정과 일치한다 — "청산은 대기 지정매수의 0.1~1%".

## 3. 예측 vs 실제 — 9.2배 벌어진다

자유모수 없는 물리적 예측: 호가를 $V$ 만큼 먹으면 어디까지 가는가.

| | 중앙 | p25 | p75 |
|---|---|---|---|
| $u_{pred}$ | **0.0182%** | 0.0106% | 0.0447% |
| $u_{act}$ (10분 최대 역행) | **0.2230%** | 0.1289% | 0.5480% |
| **$u_{act}/u_{pred}$** | **9.2배** | 1.7 | 13.8 |

$$\mathrm{corr}(\log u_{pred}, \log u_{act}) = -0.185 \quad
\mathrm{corr}(\log(V/D), \log u_{act}) = \mathbf{-0.045} \quad (n=21)$$

| 강제분 측정 방식 | corr |
|---|---|
| 전체 테이커 물량 $V_{60}/D$ | **+0.573** |
| $\lvert dOI\rvert\cdot OIV/D$ (순변화) | +0.224 |
| **실현 청산 (Bybit 전건)** | **−0.045** |

## 4. 해석 — 두 가지가 가능하고, 둘째가 더 유력

### (a) 감쇠 가설의 반증? — **아니다. 검정력이 없다**

$n=21$ 에서 상관의 SE $\approx 1/\sqrt{18} = 0.24$.
$-0.045 \pm 0.24$ 는 $+0.224$ 를 **배제하지 못한다.**

더 중요하게, **이 40시간에 캐스케이드가 없었다** (최대 클러스터 \$2.26M).
$V/D$ 범위가 0.65%~7.6% 로 좁아, 상관 0 은 "관계 없음"이 아니라 **범위 제약**이다.

### (b) $D$ 가 관측값이 아니다 — **9.2배의 정체** ← 유력

화면의 호가는 확정 물량이 아니다. 마켓메이커·봇이 넣었다 뺐다 한다.
실측(`w_survival.py`, 21종 636이벤트): 1% 이내 호가가 **중앙 3.4배 / p90 17배** 얇아진다.
극단일(2025-10-10)에는 109~523배까지 가는데, `DEPTH_FINDINGS.md` 가 보고한 것은 후자다 —
**그 극단값을 전형값처럼 인용하면 안 된다.**

$u_{pred}$ 는 호가가 가만히 있다고 가정한다. 안 그렇다.

$$\log X = a + \gamma\log V - \gamma\log D_t - \gamma\log W$$

$W$ = 잔존율. **$u_{act}/u_{pred}$ 의 산포 [1.7, 13.8] 가 곧 $W$ 의 분포다.**
그리고 $V/D_t = 0.65\%$ 가 작아 보이는 것도 **분모가 허수**이기 때문이다.

$\gamma$ 만 두 방법에서 일치한 것도 일관된다 — $W$ 는 곱셈 상수라 기울기를 안 건드리고
절편과 분산만 옮긴다.

상세는 `PROB_MODEL.md` §9.

## 5. 한계 (인용 시 반드시 함께)

1. **캐스케이드 부재.** 40시간 한 구간, 최대 클러스터 \$2.26M. 범위 제약.
2. **거래소 교차.** Bybit 청산 × Binance 호가·가격. 메이저는 가격이 붙어 다니지만 동일하지 않다.
3. **Bybit 단일 거래소.** perp 점유율 10~15% 이므로 전 거래소 합산이면
   $V/D$ 는 **5~6%** 일 수 있다. 여전히 작지만 0.65% 만큼 극단은 아니다.
4. **알트 편중.** BTC/ETH 는 REST 도달범위(0.19%/0.56%)가 짧아 밴드 3개 미만으로
   대부분 탈락. 유효 27건 중 BTC 1 / ETH 7 / SOL 11 / DOGE 4 / XRP 2 / ADA 2.
5. **롱청산 편중.** \$17.1M vs 숏 \$9.0M — 하락 구간이었다. 레짐 일반화 불가.
6. $u_{act}$ 는 10분간 시장 전체 움직임이지 그 청산의 충격만이 아니다.
