# H3-maker 검정 — 캐스케이드 아래 지정가 사전 배치

**데이터**: Binance USD-M, BTCUSDT 2020-09-01~2026-07-30 / ETH·SOL·XRP·DOGE 2021-12-01~2026-07-30
이벤트 탐지 5분봉(metrics 해상도 제약), **체결·수익 판정 1분봉**(심볼당 약 310만 바)
**실행일**: 2026-07-31

## 용어 정의 (이전 문서의 'depth'를 offset으로 개명)

**offset = 가격 거리이지 물량이 아니다.**

```
트리거 바 종가 63,000 (이 바에서 급락 + OI 급감 발생)
offset 2.0%  ->  63,000 x 0.98 = 61,740 에 지정가 매수 배치
offset 5.0%  ->  63,000 x 0.95 = 59,850 에 지정가 매수 배치
```

## 결론

**청산 채널이 수익의 원천임이 플라시보로 확인됐다.** 단순 "낙폭 매수"는 0을 번다.

## 1. 플라시보 검정 (가장 중요)

15분 보유, 고정 offset, maker 비용 7bp, 1분봉 체결 판정:

| offset | **LIQ** (급변+OI급감) | | | **CTRL** (급변+OI유지) | | |
|---|---|---|---|---|---|---|
| | 평균(bp) | t | 승률 | 평균(bp) | t | 승률 |
| 0.5% | **+50.6** | 2.3 | 61.8% | −21.2 | −1.6 | 51.6% |
| 1.0% | **+64.2** | 2.2 | 62.8% | −6.6 | −0.4 | 52.3% |
| 1.5% | **+97.0** | 2.6 | 64.6% | −8.4 | −0.4 | 55.1% |
| 2.0% | **+129.6** | 2.6 | 70.7% | +0.1 | 0.0 | 58.0% |
| 3.0% | **+212.8** | 2.6 | 74.0% | −17.8 | −0.4 | 60.8% |
| 5.0% | **+412.5** | 2.7 | 82.5% | −11.2 | −0.1 | 59.2% |

체결률은 두 그룹이 사실상 동일하다(LIQ 66.5/49.7/37.2/28.4/17.8/9.2%,
CTRL 70.8/53.1/36.9/28.9/18.2/8.7%) — 비교 가능한 표본이다.

**CTRL은 전 구간에서 0 또는 음수이고 유의하지 않다.** 즉 "큰 낙폭 뒤에 지정가를 깔면 번다"가
아니라 **"강제청산이 동반된 낙폭 뒤에 깔아야 번다"** 이다. 청산 채널이 원천이다.

부가 관찰: CTRL은 중앙값이 양수(+6.9~+49.1bp)인데 평균이 음수다 — 두꺼운 좌측 꼬리가
평균을 먹는다. LIQ는 중앙값과 평균이 모두 양수다.

## 2. 역선택 반론은 기각됐다

지정가는 "가격이 거기까지 왔을 때만" 체결되고, 왔다는 것은 캐스케이드가 계속된다는
신호이므로 체결 표본이 나빠야 한다는 것이 표준 반론이다. 데이터는 반대다 —
**offset이 깊어질수록 체결조건부 수익과 승률이 단조 증가**한다(+50bp/61.8% → +412bp/82.5%).
군집을 지나 얇은 구간에 도달할수록 반등이 크다는 가설과 일치한다.

**이벤트당 기대값은 offset에 거의 무관하게 33~38bp로 평평하다** — 깊을수록 드물게
체결되지만 그만큼 크게 먹어 상쇄된다.

## 3. 1분봉 체결 판정이 5분봉 결과를 확인했다

| offset | 5분봉 판정 | 1분봉 판정 |
|---|---|---|
| 0.5% | +50.4bp | +50.6bp |
| 2.0% | +129.5bp | +129.6bp |
| 5.0% | +371.5bp | +412.5bp |

체결률은 동일하다(5분봉 저가가 닿았다면 그 안의 어떤 1분봉 저가도 닿았으므로 당연).
개선된 것은 진입 시점과 선도수익 측정 기준이며, 결과는 유지된다.
**앞선 결과가 판정 조악함의 산물이 아니다.**

관통 요구(지정가를 뚫고 지나가야 체결 인정)를 걸면 얕은 배치만 약해진다:
0.5% offset은 50bp 관통 요구 시 +18.7bp(t=0.7)로 소멸, 5% offset은 +389bp로 유지.
깊은 주문은 가격이 관통하므로 체결이 확실하고, 얕은 주문은 바닥 찍고 반등하는 경우라
큐 뒤에 있으면 못 받는다.

## 4. 적응형 배치거리는 고정을 이기지 못했다

15분 보유 기준:

| 방식 | 최고 이벤트당 기대값 | 최고 t | 최고 승률 |
|---|---|---|---|
| fixed (상수 %) | **38.1bp** (5%) | 2.7 | 82.5% |
| bar (×트리거 바 낙폭) | 37.3bp (×0.5) | **4.0** (×2.0) | **84.4%** (×2.0) |
| sigma (×직전 변동성) | 36.7bp (×16) | 2.3 | 76.7% |
| doi (×OI 급감률) | 32.3bp (×2.0) | 2.2 | 76.7% |

`bar` 방식은 배수 2.0에서 t=4.0, 승률 84.4%로 통계적 품질이 가장 좋지만 체결률이
7.4%로 붕괴해 이벤트당 기대값은 14.8bp에 그친다. sigma/doi는 개선이 없다.

**함의**: 이벤트 크기에 단순 비례시키는 조악한 적응은 상수를 이기지 못한다. 따라서
L(p)의 가치는 "이벤트가 크니 멀리 건다" 같은 규칙으로는 대체되지 않는 것 —
**실제 공백의 위치를 아는 것** 에서 나와야 한다. L(p)가 넘어야 할 기준선은
**고정 offset 2~3%** 이다.

## 5. 남은 리스크

- **MAE가 크다.** 15분 보유에서 5%분위 −790~−1,059bp, 60분 보유에서 −2,507bp.
  체결된 거래의 5%는 −8~−25% 끌려간다. **레버리지를 쓰면 이 전략 자체가 청산된다.**
- 깊은 offset은 표본이 작다(5%에서 n=40, bar×2.0에서 n=32).
- offset 6종 × 방식 4종 × 지평 2~3종 × 관통 3종을 탐색했다. offset에 대한 단조성과
  플라시보 통과가 우연이 아님을 시사하지만 t값은 다중검정 보정 전이다.
- 1분봉도 틱은 아니다. 큐 우선순위·바 내부 경로는 여전히 미반영이며, aggTrades로
  내려가야 확정된다.
- 5개 심볼 한정. 알트로 넓히면 표본은 늘지만 유동성이 낮아 실제 체결 품질은 나빠진다.
