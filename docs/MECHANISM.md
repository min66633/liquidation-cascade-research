## 0. 한 문단 요약

가격이 급락할 때 강제 매도자가 나타난다. 그 물량은 **규모와 무관하게** 가격을 거의
밀지 못한다(실측: $V/D$ 지지집합을 42배 넓혀도 지수 $b\approx0.04$, 꺾임 없음 —
`DEPTH_FINDINGS.md`). 그러나 그들이 존재한다는 사실은 **"이 움직임이 정보가 아니라
포지셔닝에서 나왔다"** 를 알려준다. 정보 없는 매도의 반대편에 서면 유동성 공급 프리미엄을
받는다. 따라서 전략은 **시점을 맞추는 것이 아니라, 정보 없는 매도가 나올 가격대에 미리
지정매수를 깔아두는 것**이다.

## 2. 무엇을 대신 하는가

> **캐스케이드가 나를 체결시키게 한다.** 강제청산은 시장가로 나가고, 그것이 때리는 대상이
> 이미 깔려 있던 지정매수다. 그 자리에 있으면 프리미엄을 받고, 쫓아가면 지불한다.

실증(`maker_1m.py`, 1분봉 체결 판정):

| offset | 체결률 | 조건부 수익 | 승률 |
|---|---|---|---|
| −0.5% | 66.5% | +50.6bp | 61.8% |
| −2.0% | 28.4% | +129.6bp | 70.7% |
| −5.0% | 9.2% | **+412.5bp** | **82.5%** |

역선택 반론(깊이 들어갈수록 나쁜 표본만 체결)은 **기각** — 조건부 수익과 승률이 단조
증가한다. 지정가를 뚫고 지나가야 체결로 인정하는 보수적 판정에서도 유지된다.

## 3. 실시간 의사결정 루프

### t 시점에 계산하는 것

```
매 60초 (핫 스윕):
  1. mark ← 현재가                                  [allMids]
  2. L̂(u) ← 청산가가 mark 대비 u 인 포지션의 명목가 합   [clearinghouseState]
       - 롱청산(u<0)과 숏청산(u>0)을 분리해 두 지도 유지
       - 매 사이클 현재 mark 기준으로 재계산 → 가격이 밀리면 사정거리가 자동 확장
  3. D(u) ← 호가 깊이                                 [bookDepth / L2]
  4. π̂(u) ← L̂(u) / (L̂(u) + Î(u))    정보 없는 흐름 비중 추정
  5. Ŝ(u) ← 무조건부 생존함수 (통상 가격동역학, L 로 조건부화 불가)
  6. EV(u) = Ŝ(u)·[r₀ + ρ·π̂(u)] − c_fee
```

### 결정

```
  양방향으로 사다리 배치:
     아래(매수): w(u) ∝ max(EV(u), 0),  u < 0
     위 (매도): w(u) ∝ max(EV(u), 0),  u > 0
  방향 예측 없음. 비대칭은 예측하는 것이 아니라 지도에서 관측된다.
```

### 청산 규칙

```
  보유 지평 15~60분 (되돌림이 그 안에 끝남 — 극단점까지 중앙 10분)
  손절 없음 / 레버리지 없음  ← 아래 제약 참조
```

## 4. 엣지의 소재 — 한 항에만 있다

$$\mathrm{EV}(u) = S(u)\big[r_0 + \rho\,\pi(u)\big] - c_{\text{fee}}$$

| 항 | 조건부화 가능? | 근거 |
|---|---|---|
| $S(u)$ 체결확률 | **불가** *(단 아래 주 참조)* | 청산이 경로를 안 밈. 지지집합 42배 확장 후에도 $b\approx0.04$ (클러스터 t=8.0) |
| $r_0$ 기본 되돌림 | 상수 | — |
| $\pi(u)$ 상대 정보성 | **가능** | LIQ +41.8bp vs CTRL −23.9bp (격차 65.7bp) — **taker 판**, `event_study_h2.py`, 전량진입 |

> **표기 주의** — 위의 $b\approx0.04$ 는 **충격함수 지수**(청산량이 가격을 미는 탄력성,
> **기각됨**)다. 2026-08-02 에 확정된 **구조식 기울기 $\gamma = 0.875$** 와 **다른 양**이다.
> $\log X = a + \gamma\log(V/D)$, 표본 외 $R^2 = 0.338$ (21종). 섞어 쓰지 말 것
> (`PROB_MODEL.md` §0).
>
> **"$S(u)$ 조건부화 불가"는 무조건부 곡선에 대한 판정이다.** 사건별 조건부 분포
> $\mathbb{P}(X\geq u \mid \mathcal{F}_t)$ 는 아직 검정하지 않았다. `PROB_MODEL.md` §3.

**무차별성 정리**: 정보가 없으면 $S(u)\cdot\mathbb{E}[r|u] \approx$ 상수다. 24개 레벨
전부 EV 42~52bp(비용 전)로 평평했다($S$ 0.79→0.07, $\mathbb{E}[r]$ +65→+727bp, 곱이 불변).
단 이 표본은 **k=8σ·dOI≤−2% 롱청산 295건**이다 — 무조건부는 *배치거리*에 대해서지
이벤트 선택에 대해서가 아니다.

> **넘어야 할 기준선은 이벤트당 33~38bp(비용 후)** 이고, 그것을 넘길 수 있는 유일한
> 항이 $\pi(u)$ 다. 세 추정이 여기서 일치한다 — hazard 42~52bp(비용 전) → 35~45bp(후),
> maker offset 2% 36.8bp, taker 41.8bp. 진짜 무조건부 대조군인 CTRL 은 **0bp** 다.
> $\pi$ 로 조건부화한 EV가 33~38bp를 못 넘으면 이 연구는 고정 offset 2~3%와 다를
> 바 없고, L(p)를 볼 이유가 없다.

## 5. 왜 $\hat L$ 이 $\pi$ 의 대용이 되는가 (그리고 어디가 새는가)

정보 없는 매도 흐름은 두 층이다.

$$U(u) = \underbrace{L(u)}_{\text{강제청산: 관측 가능}} + \underbrace{\Sigma(u)}_{\text{재량 손절: 관측 불가}}$$

구조적으로 분리된다 — 실측(50,551 포지션): 현재가 **0–5% 구간의 격리 비중 21.9%**,
50%+ 구간은 1.1%. 근접할수록 격리가 늘어난다(전체 평균 4.9%).

- 격리·고레버리지 = 근접 강제청산의 주된 공급원 → $L(u)$ 에 잡힘
- 교차마진(전체의 97%) = 청산가가 멀어(중앙 진입가 −38%) 강제청산 대상이 아님.
  이들은 격리 스퀴즈가 만든 움직임을 **보고 재량으로 손절**한다 → $\Sigma(u)$, 안 잡힘

**새는 곳**: 근접 구간에서도 격리는 21.9%뿐이다. 나머지 78%는 교차이고, 그 층의 손절
행동은 지도에 없다. $\hat L$ 은 $U$ 의 부분집합일 뿐이며, 이것이 Q2 검정의 최대 약점이다.

## 7. 현재 검정 상태

| # | 문항 | 상태 |
|---|---|---|
| Q1 | 실현 청산이 $\hat L$ 두꺼운 곳에 집중되는가 (대표성) | **데이터 대기** (유효 관측 3건) |
| **Q2** | $\mathbb{E}[r\mid\text{fill}]$ 가 $\hat L$ 의 증가함수인가 | **v2 핵심**, Q1 통과 후 |
| Q3 | $\pi$ 조건부 EV > **33~38bp/이벤트(비용후)** | Q2 통과 후 |
| Q4 | $V/D$ 극단에서 충격항이 살아나는가 | **부분 검정 — 꺾임 증거 없음.** $V/D\ge10$ 은 n=31 로 여전히 미관측 |

**Q1이 문지기다.** $\hat L$ 이 시장 전체 강제 흐름의 위치를 담지 못하면 $\pi$ 추정 자체가
불가능하고, Q2~Q3는 성립하지 않는다.

## 8. 폐기된 주장 (앞선 판에서 과장했던 것)

| 앞서 "기각"이라 쓴 것 | 실제 |
|---|---|
| 강제청산이 일반 거래량보다 특별한 충격 | **재검정 결과 미결.** 잡음 지배 표본($59 중앙값)에서 돌렸고, 임계를 걸면 계수가 0.0007→0.204로 상승. 다만 Bybit 부분표본 vs Binance 전량 대조라 명세 오류가 남음 |
